📊 Sales Data Warehouse & Power BI Dashboard

This project showcases the complete development of a Sales Data Warehouse and Business Intelligence Dashboard designed to support data-driven decision-making.

🔧 Key Features

Star Schema Design — Structured for efficient querying and reporting.

ETL Process (SSIS) — Includes both initial and incremental data loading.

Slowly Changing Dimensions (SCDs) — Tracks historical changes in dimension data.

Columnstore Indexes — Optimized for high-performance analytical workloads.

Data Warehouse in SQL Server — Centralized repository for clean, integrated data.

Power BI Dashboard — Interactive visualizations highlighting:

Sales trends over time

Profit performance by region and category

Product-level insights and KPIs

⚙️ Tools & Technologies

SQL Server – Data Warehouse & OLAP model

SSIS (SQL Server Integration Services) – ETL automation

Power BI – Data visualization and reporting

T-SQL – Queries, transformations, and business logic

🚀 Outcomes

The final solution enables stakeholders to analyze key business metrics, monitor profitability, and explore product performance trends with a dynamic, historical, and high-performance BI system.
